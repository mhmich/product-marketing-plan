Launch Plan


PHASE 1: Pre-Launch (4–6 Weeks Before Launch)
Objectives:

Build awareness within the DevSecOps community

Educate internal stakeholders and partners

Prepare content, campaigns, and integrations

Activities:

Positioning & Messaging Alignment:
Train sales, marketing, and support teams on new positioning.
Owner: Product Marketing Manager (PMM)
Assets Needed: Messaging document, internal FAQ

Audience Segmentation & Persona Mapping:
Identify key DevSecOps buyer/influencer personas in CRM.
Owner: Marketing Operations
Assets Needed: Ideal Customer Profile (ICP) persona brief

Integration Readiness:
Ensure ZAP has plug-and-play integrations with Jenkins, GitHub Actions, GitLab, etc.
Owner: Product/Engineering
Assets Needed: Updated GitHub repositories, integration guides

Launch Content Creation:
Develop blogs, one-pagers, how-to guides, demo videos.
Owner: Content Marketing
Assets Needed: Blog calendar, demo scripts, PDF assets

Landing Page:
Create a focused landing page for DevSecOps users.
Owner: Web/Design
Assets Needed: Web copy, devsecops.zaproxy.org

Customer Advisory Board Review:
Share early release with advocates and collect testimonials.
Owner: PMM/Customer Success
Assets Needed: Net Promoter Score (NPS) feedback, quotes

Internal Enablement:
Provide GTM toolkit to Sales Development Representatives (SDRs), Account Executives (AEs), Customer Success Managers (CSMs).
Owner: PMM/Sales Enablement
Assets Needed: Sales decks, talk tracks, objection handling documents

PHASE 2: Launch (Week of Launch)
Objectives:

Create buzz

Drive high-value conversions

Generate top-of-funnel demand

Activities:

Press Release / Blog Post:
Announce new DevSecOps positioning and integrations.
Owner: Public Relations / Communications
Assets Needed: Blog post, quotes from Checkmarx and users

Email Blast:
Email existing users and developer security audiences.
Owner: Marketing
Assets Needed: Launch email series (tease, reveal, call-to-action)

Webinar: “CI/CD Security at Scale with ZAP”:
Live product demo for DevSecOps use case.
Owner: PMM / Sales Engineer
Assets Needed: Presentation deck, demo pipeline, registration page

Launch Video:
90-second animated explainer showing ZAP in CI/CD.
Owner: Creative / Product
Assets Needed: Video file, landing page embed

Social Media Campaign:
LinkedIn, Twitter/X, GitHub sponsor banner.
Owner: Social Media Manager
Assets Needed: Post copy, branded visuals, hashtags (#DevSecOps #ZAPProxy)

GitHub Launch Post:
Pin announcement in ZAP GitHub repository and update README.
Owner: Engineering
Assets Needed: Updated README.md, issue comments

Partner Enablement:
Co-market with DevSecOps tooling partners (e.g., GitLab, Jenkins).
Owner: Alliances / PMM
Assets Needed: Partner landing pages, joint webinars

PHASE 3: Post-Launch (Weeks 2–8)
Objectives:

Drive adoption and retention

Capture feedback for iteration

Prove ROI and impact

Activities:

Use Case Deep Dives:
Weekly blog/tutorial showing ZAP in DevSecOps scenarios.
Owner: Content
Assets Needed: Blog calendar, visuals

Follow-Up Webinar / Q&A:
Deeper dive into integration questions from the field.
Owner: PMM / Sales Engineer
Assets Needed: FAQ deck, GitHub repository link

Customer Stories & Case Studies:
Publish early adopters’ success stories.
Owner: Customer Marketing
Assets Needed: Case study PDF, quotes

Product Usage Nudges:
In-app tips, email nudges for key activation steps.
Owner: Product Marketing / Lifecycle
Assets Needed: Email flows, tooltips

Community Campaigns:
“Show us your pipeline” contest, GitHub badges, contributor shoutouts.
Owner: Developer Relations / Community
Assets Needed: Swag, GitHub templates, leaderboard

Pipeline Review with Sales:
Monitor lead quality, feedback loops with SDRs.
Owner: Sales / PMM
Assets Needed: Weekly reports, updated collateral

METRICS TO TRACK
Awareness & Reach:

Blog views

Social media shares

Video views

Webinar registrations and attendance

GitHub stars, forks, downloads

Activation & Engagement:

Number of CI/CD integrations installed

Time to first scan

Conversion from trial to active user (if applicable)

Pipeline & Revenue:

Qualified leads from campaign

Meetings booked by SDRs

Enterprise inquiries / Proofs of Concept (POCs) initiated

RESOURCING
Function	Role in GTM

Product/Engineering	Integration support, documentation updates
Developer Relations	Engage GitHub, Reddit, DevSecOps community
Sales Enablement	Trains field on value propositions and objections
Content & Creative	Writes copy, produces assets
Demand Generation	Runs campaigns, owns lead funnel
